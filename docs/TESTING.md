# LuciControl 验证流程

2026-09-30，对应 `/Applications/LuciControl.app`（已接管这台 Mac 的 lucirund）。

**准备**
- Mac：菜单栏有 LuciControl 图标。想看日志：`tail -f ~/Library/Application\ Support/lucirund/logs/lucirund.log`。
- 手机：Luci Run（TestFlight 15），Agent 标签 →「我的设备」里有 fatMac。
- 每一步的「预期」不符就记下步骤号和现象；日志最后几行一起发我。

## 1. 面板基础

| 步骤 | 预期 |
|---|---|
| 点菜单栏图标 | 面板在图标下方打开，底栏绿点「共享中」 |
| 再点图标 | 面板收起 |
| 打开后点面板外面 / 按 Esc / ⌘-Tab 切到别的 App | 都收起 |
| 右键图标 | 菜单：打开面板、暂停共享、设置…、退出 LuciControl |
| 面板打开时把鼠标停在底栏「共享中」上 | 提示「点击暂停共享」 |

## 2. 会话开关（核心）

| 步骤 | 预期 |
|---|---|
| 首页 | 两个小节：YPTD-MOBILE-APP、FASTLLM，会话带左侧色条和 ON/OFF；小节标题后面是「已共享/总数 会话」 |
| 手机上打开 fatMac 的会话列表，记下条数 | 和 Mac 上 ON 的条数一致 |
| Mac 上把一条 ON 关成 OFF | 行变灰；小节计数减一；手机列表立刻少这一条（1 秒内） |
| 手机正开着的那条被关掉 | 手机那条会话退出或提示不在共享目录里 |
| 再打开 | 手机上回来 |

## 3. 添加目录

| 步骤 | 预期 |
|---|---|
| 底栏「+ 添加目录」 | 添加页：Agent 只有 Codex 可选；「检测到的目录」列出 Codex 用过、还没共享的目录 |
| 勾一个（比如 lucirund）或「选择…」挑一个；共享方式保持默认（共享现有会话 开，新会话自动共享 关）；点「添加 N 个目录」 | 回到首页，多出一个小节；手机上出现这个目录的已有会话 |
| 在这个目录里新开一个 Codex 会话：终端 `cd 目录 && codex`，随便说一句 | 15 秒内 Mac 面板出现新会话，默认 OFF；手机上看不到 |
| 把它打开 | 手机上出现 |
| 右键小节标题 →「新会话自动共享」勾上，再新开一个会话 | 新会话默认 ON |
| 右键小节标题 →「停止共享此目录」 | 小节消失；手机上目录和会话消失 |
| 把一个文件夹从 Finder 拖到菜单栏图标上 | 面板打开到添加页，路径已填好（这条没试过，请重点看） |
| 添加「文稿」或「桌面」里的目录 | 系统弹一次授权框，写的是 LuciControl |

## 4. 暂停 / 恢复

| 步骤 | 预期 |
|---|---|
| 点底栏「共享中」 | 变「共享已暂停」灰点；菜单栏图标变淡；手机上 fatMac 离线 |
| 再点 | 「共享中」；手机上 fatMac 几秒内重新在线 |
| 右键菜单的「暂停共享 / 恢复共享」 | 同上 |

## 5. 设备页

| 步骤 | 预期 |
|---|---|
| 底栏手机图标 | 设备页列出你的手机，在线是绿条 |
| 手机上打开一条会话 | 该设备副标题「在线 · 正在看 1 个会话」（几秒内） |
| 把这台手机的开关关掉 | 副标题「已禁用访问」；手机上 fatMac 提示「这台机器收回了共享」或离线 |
| 再打开 | 手机上退出会话页重进，重新连上 |
| 右键设备 →「移除设备」 | 从列表消失，出现在「已移除的设备」里；「恢复」放回 |
| 设置 →「已配对设备」 | 台数正确 |

## 6. 运行状态（可选）

| 步骤 | 预期 |
|---|---|
| 手机上给一条会话发消息，让 Codex 跑个命令 | Mac 面板该会话绿条「运行中」；标签上没有橙点 |
| Codex 停下来等审批 | 该会话橙条「等待审批」；Codex 标签右上角橙点；菜单栏图标右上角橙点 |
| 手机上批准 | 橙点消失 |

## 7. 退出与重启

| 步骤 | 预期 |
|---|---|
| 底栏电源图标 | 确认框，说明退出后手机连不上；有手机连着时多一行 |
| 确认退出 | 菜单栏图标消失；手机上 fatMac 离线；终端里 `pgrep -fl "lucirund run"` 没有输出 |
| 重新打开 /Applications/LuciControl.app | 图标回来；手机上 fatMac 在线；共享目录和每条会话的开关和退出前一样 |
| 注销再登录（或重启 Mac） | LuciControl 自动出现在菜单栏 |

## 8. 设置页

| 步骤 | 预期 |
|---|---|
| 底栏齿轮 | 已配对设备、更新（目前是占位，阶段 5 做）、通用、本机、退出 |
| 本机 | 机器名 fatMac、账号 xiaolu、Codex 版本、令牌 2026-10-28 到期 |
| 「开机时启动」关掉再打开 | 系统设置 → 通用 → 登录项与扩展 里 LuciControl 跟着消失、出现 |
| 「体检」「打开日志」 | 还没接，点了没反应（已知） |

## 先别做的

- 不要用 `--data-dir` 加正式中继跑首次使用流程：那会在你的账号下多登记一台机器，现在没有删除入口。首次使用我用本地中继验证过，想亲眼看的话告诉我，我起本地中继带你走一遍。
- 不要再运行 `lucirund install` 或 `lucirund setup`：它会把命令行版的服务装回去，和 LuciControl 抢身份。
