LuciControl 0.3.3（9）

  • 手机上可以给每条会话选「请求批准 / 替我批准 / 完全访问」，和 Codex app 一样：下一回合起生效，电脑上的终端也跟着改；终端里用 /permissions 改的，手机 10 秒内跟上。完全访问只有机器主人的手机能开，主人的手机也不再被「完全访问」锁住。
  • 修复手机上档位显示不准的问题：会话列表每次刷新都会把已经知道的档位丢掉，终端刚开的会话改档位时通知也被忽略。
  • 会话列表的刷新从 15 秒改为 10 秒，终端里新开的会话更快出现在手机上。

适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。配合手机端 Luci Run 0.1.0 (21) 使用。
