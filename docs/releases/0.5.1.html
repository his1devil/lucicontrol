LuciControl 0.5.1（13）

  • Claude Code 回答里提到的图片在手机上直接显示：截图、渲染结果，不管写成 Markdown 图片、代码片段里的路径还是一句话里的路径都认得；相对路径按会话目录找，紧贴中文标点的路径和带空格的 macOS 截图名也认得。从对话记录读出来的历史也一样。
  • Claude Code 的每次工具调用都报给手机：读文件、搜索、子任务这些原来不显示，现在手机上合成一行摘要，点开能看每一步和输出；改文件带上改动内容，手机上点一下看 diff。
  • Claude Code 的任务清单（TodoWrite）在手机上显示成带进度的计划卡片，计划模式的计划文字也是。
  • Codex 会话里，回答提到的相对路径图片也按会话目录找。
  • 内置 lucirund 0.5.1。

适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。配合手机端 Luci Run 0.1.0 (24)：会话的排版、Claude 会话的样式在手机上更新；老版本的手机照常能用，只是看不到逐步的工具记录。
