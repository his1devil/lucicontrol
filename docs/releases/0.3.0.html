LuciControl 0.3.0（6）

  • 修复部分 Mac 上 CPU 占用过高、启动后无响应的问题：Codex 一启动就退出时，后台不再每秒反复拉起它，改为逐步延长等待，日志里会写明原因。
  • 修复添加共享目录或切换「新会话自动共享」后，其他目录里原本私有的新会话变成对手机可见的问题。目录套目录时，以最里层目录的设置为准。
  • 手机在线状态更准确：暂停共享或中继断开时不再显示过期的「在线」，已不在账号里的手机会从列表移除，并区分「在线」和「在线 · 未连接这台 Mac」。
  • 移除设备在后台确认禁用后才生效；会话、设备开关操作失败时恢复原状并提示原因。
  • 注销、重启、关机时不再弹出退出确认；「选择…」文件框不再被面板遮挡；配对页文案完整。
  • 设置页显示中继与 Codex 的连接问题、令牌能否自动续期；「体检」「打开日志」可以使用，后台崩溃信息会写进日志。
  • 跳过某个版本后不再显示更新提示；后台一直没有就绪时可以选择「仍要安装」。

App 与内置后台版本统一为 0.3.0。适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。手机端无需更新。
