LuciControl 0.1.2（5）

  • 修复确认框被菜单栏面板遮挡的问题：移除、退出和开机启动提示始终显示在面板前方，关闭后恢复面板层级与焦点，支持 Escape 取消。
  • 修复浅色背景下菜单栏面板圆角外出现白色尖角的问题，统一毛玻璃与内容的透明裁剪。
  • 会话与共享目录增加可见的移除按钮。Off 只停止手机访问；移除会话同时清理列表，并记住移除状态，刷新或重启后不会再次出现。
  • 移除操作保留磁盘文件和原始 Codex 聊天记录；目录之后可以重新添加。
  • 正在运行或等待响应的会话暂时不能移除；配置保存失败会保留原列表并提示错误。

适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。手机端无需更新。
