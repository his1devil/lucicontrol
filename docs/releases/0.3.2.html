LuciControl 0.3.2（8）

  • Codex 申请沙箱之外的权限（写某个目录、联网）时，手机上会出现授权卡片，可以只给这一回合、给这次会话，或拒绝。此前这类请求在手机上没有任何显示。
  • computer use 等 MCP 工具通过 Codex 向你确认或填表时，手机上会出现对应的卡片（表单按字段类型显示，链接类可直接打开）。此前这类请求也不显示，会话会一直卡在那里等。
  • 手机通知改为「会话标题 + 要批的事」或「会话标题 + 用时」，不再显示机器名；中继已同步更新。

适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。配合手机端 Luci Run 0.1.0 (20) 使用。
